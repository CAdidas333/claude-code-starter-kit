# IP

> Intellectual property, legal, and formation tracking.

## What goes here

- **Trademarks** — filings, status, renewal dates
- **Copyrights** — if you have registered software copyrights
- **Patents** — provisional, non-provisional, deadlines, attorney communications
- **Entity formation** — LLC vs S-Corp vs C-Corp research, operating agreements, ownership splits
- **Trade secrets** — what you're protecting by keeping private, access control decisions
- **Legal deadlines** — anything with a date attached

## Why a dedicated folder

Legal stuff has deadlines. Legal stuff has money consequences. Legal stuff needs to be findable fast. Don't bury it in the general Ideas/ pile.

## Format suggestions

- One file per topic — `Patent-Timeline.md`, `Trademarks.md`, `Entity-Formation.md`
- Dates prominent at the top
- Status field — `TODO`, `filed`, `pending`, `granted`, `expired`
- Attorney contact info (if applicable) kept here so you don't have to dig

## A note on security

**Consider whether these files should even live in git.** Some legal/IP content is highly sensitive. If you're unsure, keep IP-sensitive content in a gitignored subfolder or in a separate password-protected vault, not in the public-anything part of your workflow.
