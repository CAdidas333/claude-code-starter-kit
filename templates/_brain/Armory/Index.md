## Seed Notes

The kit ships with 3 general-purpose starter notes in `Notes/` to show you what a good Armory note looks like. You can read them, edit them, or delete them — they're just examples.

## Getting started

1. Find a YouTube video, TikTok, or article you found useful
2. Copy the URL
3. In a Claude session, run `/ingest <url>`
4. The skill will download the transcript, summarize it, tag it, and add it to `Notes/`
5. Check back here — this index will have been updated

You don't need to read your notes directly. Ask Claude about a topic and the Armory MCP server will pull relevant notes in automatically.
